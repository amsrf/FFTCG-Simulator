# Board refinement — pass 1

Built with `../build_board_refined.py`. The original `board_blockout` artifacts remain available for comparison. No Godot scenes are modified.

Changes: deeper wood tones, restrained grain and edge wear, iron pins, a continuous river with widening banks and curved ripples, tapered tree branches and roots, clustered foliage and grass, broad basalt plates and narrow emissive red fissures.

`board_with_layout.png` and `board_environment.png` use the current Godot camera parameters. `board_wider_comparison.png` is an optional 10% wider view. `board_refined.blend` retains the current framing and includes packed card textures.

This is a Blender art preview. Card rows match the earlier measured layout; hands and decks remain approximate witnesses. UI, damage piles and gameplay effects are not reproduced. Cycles materials and lighting are not yet converted or validated in Godot GL Compatibility. No export is integrated into the game.
