# Board composition blockout

Generated by `../build_board_blockout.py` with Blender 4.4. No Godot scenes or gameplay settings are modified.

- `board_with_layout.png`: current camera parameters, 1920 x 1080.
- `board_environment.png`: same camera, layout proxies hidden.
- `board_wider_comparison.png`: camera distance increased 10%, framing 8.8 units instead of 8.0. Proposal only.
- `board_blockout.blend`: editable scene saved with the original camera and visible layout proxies.

Camera matches `scripts/camera_rig.gd`: 67-degree elevation, 30-degree vertical FOV, target Godot (0, .35, -.25). Coordinate mapping to Blender is (x, -z, y).

Field dimensions, row centres, row spacing and field transform come from `battle_field.tscn`, `battle_field.gd` and `game.tscn`. Cards use approximate collision dimensions and existing card art as layout witnesses; card identities, hand fan, shaders, UI, damage piles, rings, animations and shadows are not a reproduction of the running game. Final scene needs clearance checks for those elements before integration.

River position includes a visual offset to account for cards floating approximately .5 units above the board. Terrain, trees, wood and water are deliberately rough composition geometry/materials, not finished hand-painted assets. Cycles lighting is a preview and will need a separate Godot Compatibility treatment.

Rebuild from the repository root:

```powershell
& 'C:/Program Files/Blender Foundation/Blender 4.4/blender.exe' --background --python 'Blender/build_board_blockout.py'
```
